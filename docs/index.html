    GUIDED LESSONS

    จากเซนเซอร์ถึงการตัดสินใจ

    สำหรับนักศึกษาที่กำลังเริ่มเรียน AIoT

    อ่านค่าจากสิ่งแวดล้อม

    HTS221 บนบอร์ด Cucumber RS วัดอุณหภูมิเป็น °C และความชื้นสัมพัทธ์เป็น %RH เฟิร์มแวร์อ่านค่าผ่าน I²C แล้วส่ง JSON หนึ่งบรรทัดทาง USB Serial ทุก 2 วินาที

    {"temperature":25.4,"humidity":51.2}

    ลองสลับสถานการณ์จำลอง แล้วสังเกตว่าค่าใดเปลี่ยนมากที่สุด

    จำแนกด้วย k-NN

    โมเดลเก็บตัวอย่างพร้อมป้ายกำกับ 18 จุด ปรับสเกลสองตัวแปรด้วยค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานของชุดฝึก แล้วหาระยะ Euclidean ถึงตัวอย่างแต่ละจุด

    เพื่อนบ้าน 3 จุดที่ใกล้ที่สุดโหวตเลือกคำตอบ หากคะแนนเสมอกันใช้ป้ายของจุดที่ใกล้ที่สุด ลองเทียบผลกับรายการเพื่อนบ้านในห้องทดลอง

    ดูชุดข้อมูลฝึก

    ตรวจสอบผลของโมเดล

    ตั้งสมมติฐานก่อนสลับไปโหมดห้องอับชื้น แล้วเทียบผลกับเพื่อนบ้าน 3 จุด จากนั้นลองเทียบค่าจากบอร์ดในสองตำแหน่งที่มีสภาพต่างกัน

    ตัวอย่างฝึกเป็นข้อมูลสังเคราะห์ ห้องจริงอาจร้อนและชื้นพร้อมกัน แต่โมเดลนี้แสดงหนึ่งป้ายเสมอตามตัวอย่างที่รู้จัก ควรเก็บข้อมูลจริงพร้อมป้ายกำกับและแยกชุดทดสอบก่อนนำไปใช้งานจริง

    เช็กความเข้าใจ

    ถ้าเพื่อนบ้านใกล้ที่สุด 3 จุดโหวต “อับชื้น” 2 เสียง กับ “สบาย” 1 เสียง โมเดลจะตอบอะไร?

    HARDWARE SETUP

    ต่อบอร์ดจริง

    Cucumber RS รุ่น ESP32-S2 พร้อม HTS221

    อัปโหลดเฟิร์มแวร์

    1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code ที่ติดตั้ง PlatformIO แล้วเสียบบอร์ดเข้าพอร์ต Debug ด้วยสาย USB ที่รับส่งข้อมูลได้
    2. เลือก PlatformIO → Project Tasks → cucumber → Upload หรือรันคำสั่งด้านล่างจากโฟลเดอร์โปรเจกต์
    3. ตรวจว่า Serial Monitor ที่ 115200 baud แสดง JSON อุณหภูมิและความชื้น แล้วปิด Monitor เพื่อให้เว็บใช้พอร์ตได้
    pio run -e cucumber -t upload

    เปิด dashboard บนพีซี

    1. เปิดหน้าเว็บผ่าน HTTPS หรือ localhost ด้วย Chrome หรือ Edge บนเดสก์ท็อป
    2. กด เชื่อมต่อบอร์ด ในห้องทดลอง แล้วเลือกพอร์ต COM ของบอร์ด
    3. รอค่าจริงและผลจำแนก เมื่อทดลองเสร็จให้กด ตัดการเชื่อมต่อ
    แก้ปัญหาการเชื่อมต่อ

    ถ้าไม่พบ COM ให้เช็กสาย USB และพอร์ต Debug ถ้าเปิดพอร์ตไม่ได้ให้ปิด Serial Monitor หรือโปรแกรมอื่นที่ใช้พอร์ต ถ้าขึ้นว่าไม่พบ HTS221 ให้ตรวจรุ่นของบอร์ดและขา I²C SDA 41 / SCL 40
